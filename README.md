# Estudo de Interface Responsiva com Bootstrap 5

[![Deploy Status](https://img.shields.io/badge/Deploy-Vercel-black?logo=vercel)](https://pagina-com-bootstrap.vercel.app/) 
[![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3.3-7952B3?logo=bootstrap&logoColor=white)](#)

Este repositório contém um projeto de interface web desenvolvido como exercício prático para a consolidação de conceitos de front-end, design responsivo e componentes de User Interface (UI).

##  Live Demo
O projeto está publicado e pode ser acessado através da Vercel:
👉 **[Acessar o Projeto](https://pagina-com-bootstrap.vercel.app/)**

## Tecnologias e Ferramentas
*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização complementar (variáveis de cores personalizadas e ajustes de componentes).
*   **Bootstrap 5.3.3 (CDN):** Framework principal para a construção de componentes e responsividade, dispensando a necessidade de escrever CSS complexo do zero. (Tanto é que, fiz tudo pelo index.html)
*   **Vercel:** Plataforma de hospedagem (Deploy contínuo).

## Componentes e Conceitos Aplicados
*   **Sistema de Grelha (Grid System):** Construção de layouts fluidos que se ajustam automaticamente consoante o tamanho do ecrã (Mobile, Tablet e Desktop), utilizando classes como `row-cols-lg-4` e `row-cols-md-2`.
*   **Navegação (Navbar):** Menu de navegação responsivo fixo, com suporte a botões de *dropdown* e ícone hambúrguer (`navbar-toggler`) em dispositivos móveis.
*   **Carousel:** Deslizador dinâmico de imagens com indicadores de posição e controlos de navegação integrados.
*   **Cards:** Padronização visual para a exibição de conteúdos e postagens de forma organizada.
*   **Abas (Nav Tabs):** Estruturação de conteúdo interativo em secções separadas (Postagens, Tabelas de Preços e Formulário de Contacto), otimizando o espaço vertical da página.
